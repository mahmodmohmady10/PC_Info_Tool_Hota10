# PC Info Tool 2.0 — UI Update

This update refreshes the desktop interface while retaining the Phase 9 application logic.

## Visual changes
- More structured sidebar with a distinct active navigation state.
- Dark navy surfaces with a restrained blue accent and clearer contrast.
- Redesigned header with page context, refresh action, and theme selector.
- Dashboard cards with stronger information hierarchy and improved spacing.
- Updated privacy/local-processing footer and dashboard note.

## Preserved features
- Hardware data collection
- Live CPU/RAM/disk/network monitoring
- Diagnostics
- Benchmarking and benchmark history
- HTML/JSON reports
- Dark/light appearance switch

## Run
Use the existing `install_and_run.bat` or `build_exe.bat` scripts included in this project.
